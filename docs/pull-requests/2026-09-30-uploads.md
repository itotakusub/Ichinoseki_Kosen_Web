# お試しの閲覧リンクを足す(期限・台数つき。教職員と同じ範囲だけ見える)

`Uploads` → `main`

## 変更点

- 管理画面「お試しの閲覧リンク」で発行・取り消し。リンクは発行した画面で 1 回だけ見せ、表には要約だけ置く
- 公開側 guest.php は GET では使わない(下見対策)。POST + CSRF で 1 台分を使い、セッション ID を作り直して印を立てる
- 取り消し・期限切れは公開ページと地図データの API で表と突き合わせて外す
- nginx: /guest.php のクエリをログに残さない・no-referrer・回数制限
- 期限の切れたリンクは 30 日で消す(ポリシー 8 節にも書く)。退会したら発行者を外す
