# SSH ログインの知らせに「信頼済み」と「重要」を足す

`Uploads` → `main`

## 変更点

- 信頼した接続元は件名を [KosenMap] **信頼済み**SSH ログイン: 通知 にする(一覧は root だけが書ける /etc/kosenmap/ssh-trusted-ips)
- kosenmap-ssh-kick に --trust / --untrust / --list-trusted
- 信頼していない接続元の知らせには「重要」(X-Priority・Importance)を付け、本文に「今の接続を信頼する」コマンドを載せる
