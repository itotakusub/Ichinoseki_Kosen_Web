# 高専マップの使い方(来場者向け)

一関高専の校舎の地図です。行きたい部屋を探して、そこまでの道順を案内します。
Web ブラウザで開く **Web の地図** と、Android の **アプリ** があります。どちらも無料です。

---

## 1. 開き方

### Web の地図
- ブラウザで **https://ito4.jp** を開きます。インストールは要りません。
- 部屋に貼ってある **QR コード** を読むと、その部屋が地図の上で開きます。

### Android アプリ
1. アプリを入れて開きます。
2. 左上のメニューから **「マップを取得」** を押します。
3. 配られた **アクセスコード** を入れます(受付や案内の紙に書いてあります)。
4. 地図が届けば使えます。届いた地図は端末に残るので、電波の弱い所でも見られます。

> 地図には使える期限があります。期限が切れたら、もう一度「マップを取得」してください。

---

## 2. 地図の見方

- 右側の **1F〜5F・外** で階を切り替えます。
- 指で広げると拡大します。拡大すると、部屋の名前やトイレ・階段などが見えてきます。
- 外の地図で建物を押すと **「中へ 1F 2F …」** が出ます。押すとその建物の中の階へ移ります。
- 部屋を押すと **詳細** が出ます(名前・部屋番号・分類など)。

### 色分け
部屋・廊下・階段などは、種類ごとに色を分けて塗ってあります。色の見え方に関係なく区別しやすい色を選んでいます。

### 階段の印
- 階段には **「▲上行き 2〜5F」「▼下行き 1F」** のように、行ける階が出ます。
- エレベーターは **「⇅ 1〜5F」** です。

---

## 3. 部屋を探す

- 上の **検索** に部屋の名前や番号を入れます(例: 「図書館」「3-201」)。
- **カテゴリー検索** では、トイレ・階段・自販機などをまとめて探せます。
- 検索の窓が空のときは、前に探した言葉が出ます。

---

## 4. 道順を出す

1. 行きたい部屋を押して **「ここを目的地にする」** を押します。
2. 出発する場所を **「ここを出発地にする」** で選びます。
3. 地図に道順の線が出て、下に「どこで何階へ上るか」などの案内が出ます。

### 階を移るとき
設定の **「階を移るとき」** で、**エレベーター優先** か **階段優先** を選べます。
車いす・ベビーカー・大きな荷物のときは、エレベーター優先にしてください。

### 通れない場所
イベントの準備や工事で通れない道には、地図に **通行止めの印** が付きます。道順は、そこを避けて出します。
通行止めのせいで行けないときは、そのことを知らせます。

### 現在地(Android アプリ)
アプリは Wi-Fi の電波から、だいたいの現在地を出します。
- 位置の許可を求められたら「許可」を押してください。
- 建物の中では数 m ずれることがあります。部屋の名前と見比べて使ってください。

---

## 5. イベントの日(高専祭・オープンキャンパスなど)

- 画面の上に **イベントの案内** が出ます。
- イベント中は、**企画をしている場所・受付・救護・トイレ・階段・出入口** を中心に地図に出します。
  ほかの部屋は出さないことがありますが、道順は通常どおり出ます。
- **模擬店・受付・救護** などの臨時の場所も地図に出ます。

### 予定(スケジュール)
- 左下の **「📅 予定」** を押すと、催しの一覧が日ごとに出ます。
- **開催中** の催しには印が付きます。
- **「地図で見る」** を押すと、その催しの場所が開きます。
- 部屋の詳細にも **「この場所の予定」** が出ます。

### ポスター
- ポスターのある場所は、名前に **🖼️** が付きます。
- 部屋の詳細でポスターを押すと、大きく見られます。「くわしく見る」から企画のページへ移れます。

---

## 6. 履歴とブックマーク

- 部屋の詳細の **☆ ブックマーク** で、よく行く場所を覚えておけます。
- 左下の **「🕘 履歴」** で、ブックマーク・開いた場所・経路・検索した言葉を見られます。押すとその場所や経路が出ます。
- 次に開いたとき、**前回の経路** を出すかどうかを尋ねます。
- 履歴は **端末の中だけ** に残ります。**サインインしているとき** は、同じアカウントの端末どうしで揃えます。
- 経路の履歴を残したくないときは、尋ねられたときに「この端末だけ」「経路も消す」を選んでください。
- 履歴は「履歴を全部消す」でいつでも消せます。ログアウトするときにも、消すかどうかを尋ねます。

---

## 7. 見た目を変える

左下の **「表示調整」** で、文字や印の大きさ・出す種類・色分けなどを変えられます。
変えた項目は端末に覚えます。いつでも元に戻せます。

---

## 8. 困ったとき

| こんなとき | すること |
|---|---|
| 地図が出ない(アプリ) | メニューの「マップを取得」で、アクセスコードを入れ直してください |
| 「期限が切れました」と出る | もう一度「マップを取得」してください |
| 探している部屋が見つからない | 部屋番号でも探してみてください。イベント中は、案内していない部屋があります |
| 道順が出ない | 出発地と目的地が正しいか確かめてください。通行止めで行けない場合は、近くの係の人に聞いてください |
| 現在地がずれる(アプリ) | 少し歩くと直ることがあります。Wi-Fi が切れていないかも確かめてください |
| QR コードを読んでも部屋が開かない | その部屋は今は案内していません。地図から探してください |

---

## 9. 情報の扱い

- 履歴・ブックマークは、サインインしていなければ端末の外へ出ません。
- 先生の名前や、教員室・研究室の場所は一般には出していません。
- くわしくは、地図のページ下の **利用規約** と **プライバシーポリシー** をご覧ください。

わからないことは、受付・案内所の係の人に気軽に聞いてください。
